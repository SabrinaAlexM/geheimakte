Geheimakte

Zwei Teams, 25 Wörter, ein Hinweis pro Runde. Findet eure Agentinnen, bevor ihr den Attentäter erwischt.

Spielfeld mit bestimmtem Code laden:

Spiel einrichten

Alles ausser den Wörtern ist optional. Deine Einstellungen bleiben fürs nächste Spiel gespeichert.

💻 Spielart

Beim Tablet steht jedes Wort zweimal auf der Karte, einmal gedreht. So können beide Seiten vom Tisch lesen.

🔤 Wörter

«Einfach» nimmt nur Alltagswörter, die auch Kinder kennen. «Gemischt» bringt mehr Doppeldeutiges wie Bank, Schloss oder Leiter.

👥 Teams optional

Tippe auf die Figur, um eine Agentin oder einen Agenten auszuwählen.

⏱ Timer

Zeit, die das Team für den nächsten Hinweis oder fürs Raten hat. Wird auf dem Spielfeld eingeblendet und von Hand gestartet.

🔍 Wörter prüfen

Tippe auf ein Wort, das ihr schon hattet oder das nicht passt. Es wird ausgetauscht. Die Farben bleiben bis zum Start geheim.

🕵️‍♀️ Hinweis-Karte

Gib den Code ein, der auf dem Spielfeld steht. Wurden Wörter ausgetauscht, ist er länger, z. B. KXQM-DK.
